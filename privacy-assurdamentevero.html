Che cos'è questa applicazione

AssurdamenteVero è uno strumento personale, non distribuito e non accessibile a terzi. Serve esclusivamente al titolare per pubblicare e programmare contenuti sui propri account: la Pagina Facebook "AssurdamenteVero" e i profili collegati. Non ha utenti oltre al titolare, non offre alcun servizio al pubblico e non prevede registrazione o accesso da parte di altre persone.

Quali dati vengono trattati

  • Identificativi e metadati degli account del titolare restituiti dalle API di Meta: ID e nome della Pagina, ID dei contenuti pubblicati, date di pubblicazione.
  • Metriche pubbliche dei contenuti del titolare (visualizzazioni, interazioni), lette dalle API per uso statistico personale.
  • Token di accesso agli account del titolare, necessari per pubblicare.

L'applicazione non raccoglie, non riceve e non conserva dati di altre persone: nessun dato di utenti terzi, nessun contatto, nessun contenuto altrui, nessun dato di navigazione.

Dove sono conservati

I token di accesso e i dati elencati sopra restano sul computer personale del titolare, in file locali. Non esiste un server applicativo, un database remoto o un servizio cloud che li riceva.

Come vengono usati

Unicamente per pubblicare contenuti sugli account del titolare tramite le API ufficiali di Meta e per leggerne le statistiche. Non c'è profilazione, non c'è pubblicità, non c'è alcuna cessione, vendita o condivisione di dati a terzi.

Per quanto tempo

I token restano validi finché il titolare non li revoca. I dati statistici locali sono conservati finché sono utili all'attività editoriale e possono essere cancellati in qualsiasi momento.
